# Project Documentation

This repository contains a simple voice-controlled assistant implemented in Python. The assistant listens to voice commands, performs actions like opening websites, applications, and searching Wikipedia, and responds via text-to-speech.

- Language: Python
- Entry point: `jarvis.py`
- Primary libraries: `pyttsx3`, `speech_recognition`, `wikipedia`, `pyfiglet`, `webbrowser`, `pyaudio`

## Contents
- `api/` – Detailed API and function documentation
- `getting-started.md` – Installation and setup
- `troubleshooting.md` – Common issues and fixes
- `usage-examples.md` – Practical examples
