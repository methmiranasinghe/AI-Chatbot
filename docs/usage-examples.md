# Usage Examples

## Start the assistant
```bash
python jarvis.py
```

## Speak commands
- "Wikipedia Albert Einstein"
  - The assistant will read a short summary from Wikipedia.
- "Open YouTube"
  - Opens YouTube in your default browser.
- "Open Google Maps"
  - Opens Google Maps.
- "Play music"
  - Opens Spotify web in your default browser.
- "What is your name"
  - The assistant responds with its name.
- "Goodbye"
  - Exits the program.

## Tips
- Wait for "Listening..." before speaking.
- Speak clearly and pause briefly between commands.
- Background noise can reduce accuracy; the assistant auto-calibrates to ambient noise for 1 second at start of each listen.
